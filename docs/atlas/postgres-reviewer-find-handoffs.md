# Reviewer discovery handoffs

Migration 113 defines `reviewer_find_handoffs` as a request-keyed list of open staff searches. After the proposal-expertise recovery pass declines, the Find analysis route records the signed-in staff profile and bounded search settings. Concurrent attempts retain the original assignment. The table holds no proposal document or model response.

The Workbench roster reads open cases on reload. Completing a case requires a selected reviewer in the proposal's Candidates list, the assigned profile, and the current case ID. Completion removes the open case. Reviewer eligibility, contact verification, and relationship decisions are stored separately.
