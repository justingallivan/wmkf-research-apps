## Rollback

Pause Find refreshes and invitations on affected enrolled requests first. Export their stored roster rows, contact receipts, active holds and the sealed ledger. Restore the recorded known-good serving deployment using the normal Vercel production rollback procedure. Removing the allowlist and redeploying stops new pilot saves but restores the legacy enrichment behavior, so keep affected requests paused until reviewed. A deployment rollback does not reverse prior writes. Compare each affected row to its last verified receipt, account for any independent CRM/staff changes and re-hold questionable unsent contacts through the existing staff workflow. Resume only after the owner signs off on the affected requests.
