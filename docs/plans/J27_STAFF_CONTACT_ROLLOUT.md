# J27 Research staff-confirmed Find contacts

Justin will try the workflow first and tell PDs when to begin. All J27 Research requests qualify through the same production Workbench. Find reads the request’s linked Grant Cycle and broad Grant Program from Dataverse. A new proposal needs no enrollment, configuration change or deployment. The earlier [paired comparison](J27_FIND_STAFF_CONTACT_PILOT.md) is an optional study, independent of staff access.

## Using Find

1. Open **Workbench → Peer Review → Find** on your own proposal and run Find normally.
2. When an initial Claude suggestion has a held search or institutional-page email, open **Verify contact only**. Check that a current institutional source identifies the same reviewer and displays the exact mailbox. Leave uncertain contacts held.
3. Enter the institutional evidence URL and select **Save verified email only**. If the row changed while it was open, reload and review the current lead before saving.
4. After reload the ordinary card shows the saved email and the ownership source. The contact decision is request-local. Identity, CRM, eligibility, same-institution and coauthor decisions remain independent. The existing lead-PD or superuser authorization controls who may save on a proposal.

A search result or profile match cannot issue a staff receipt. Other cycles and programs retain their existing workflow. If a wrong mailbox or unexpected hold change appears, pause saves and invitations for the affected request and give the release owner its request number and reviewer name. Preserve the current receipt before any correction. If rollback is needed, restore the last known-good deployment, then reconcile affected rows and holds before resuming Find.
