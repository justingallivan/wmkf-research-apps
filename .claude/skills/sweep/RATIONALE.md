# Sweep Rationale

This sidecar preserves the history behind `/sweep` without placing that history
in the normal skill prompt.

The skill was added after fact-level doc fixes repeatedly patched the visible
line while leaving contradictory restatements in the same file or nearby durable
surfaces. The successful operating pattern was to state one fact, search likely
restatements, classify every hit, edit all live stale statements in one pass,
and re-run the same search terms before claiming completion.

Active instruction belongs in `SKILL.md`. Incident history belongs here.
