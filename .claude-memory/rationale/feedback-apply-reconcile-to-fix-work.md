# feedback-apply-reconcile-to-fix-work Rationale

This sidecar preserves the incident history behind the active memory without
placing that history in the normal recall rule.

The rule was added after review-finding fold-ins repeatedly created new
unverified claims while correcting earlier ones. The durable correction is to
treat every fix as fresh authored work: verify new claims, reconcile related
restatements, and check the surrounding structure for contradictions.
