# feedback-falsify-not-confirm Rationale

This sidecar preserves the incident history behind the active memory without
placing that history in the normal recall rule.

The rule was added after scope/quantity claims were verified by searches shaped
only to confirm the current hypothesis. The successful correction was to make
the grammar of the claim choose a disconfirming query: search the complement
set, derive denominators independently, and label claims that cannot be
falsified.
