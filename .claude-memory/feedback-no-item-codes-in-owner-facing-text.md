## Recall Rule
Read before writing a message to the owner, a meeting agenda, a shared page/artifact, or any decision list drawn from a plan or alignment log that uses item codes.

Do: name each item by what it is ("who gets notified about missing cycle dates", "what the files-ready flag means"). If a cross-reference to a doc row is useful, put the code last, in parentheses, or leave it in the doc only.
Do not: use codes like A1, B1 Q3, C4, R2, X2, F1, D7 as the item's name in chat, agendas or shared pages.

**Why:** owner, 2026-10-27, while working through the J27 decision list: "I really don't understand your nomenclature of C, R, B. And I know no one else will." The codes are an artifact of `docs/plans/J27_ALIGNMENT_LOG_2026-10-24.md`, not shared vocabulary.

**How to apply:** codes may stay inside the alignment log and other internal docs as stable row ids; owner- and colleague-facing text uses plain names. Related: [[feedback-staff-ui-never-shows-internal-ids]], [[feedback-user-facing-error-copy-voice]].
