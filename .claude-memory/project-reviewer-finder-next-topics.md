## 1. Extend (and ideally make configurable) the Claude reviewer-call timeout — ✅ SHIPPED S223 (`493f4cd`, deployed)
Admin-configurable wall-clock search budget: Dataverse setting `reviewer.time_budget_seconds` (default 600s, clamped [120,800]), superuser `/admin` card + `GET/PUT /api/admin/reviewer-time-budget`. All 5 reviewer search routes pinned at `maxDuration: 800` (Pro cap) with an app-level AbortSignal deadline (maxDuration is build-time-static → can't be a live setting). See [[project-reviewer-prompt-dataverse-migration]] sibling work and `docs/REVIEWER_TIMEOUT_BUDGET_PLAN.md`.

## 2. Use recency/dates to improve reviewer identification (prioritize current role over the digital tail) — ✅ SHIPPED S223–S224
**Was (Justin's framing):** a reviewer's long digital tail (grad → postdoc → current) is dominated by the postdoc stage, but the CURRENT role (often a new professor, sparse-but-correct) is who we want. **Shipped:** ranking rebalanced so recent in-area publication activity dominates and h-index/citations left the rank order (S223, `c694bcb`); PubMed affiliation is recency-weighted; identity-gated affiliation evidence pins ORCID-current over OpenAlex-last-known over PubMed-recency. The 2026-07-21 reconciliation made those semantics explicit on the cards: PubMed is “publication affiliation” and OpenAlex is “last known,” not asserted current. Full design + Codex-round history: `docs/REVIEWER_RECENCY_WEIGHTING_PLAN.md`, `docs/REVIEWER_AFFILIATION_CONTACT_RECONCILIATION_PLAN.md`, and [[project-reviewer-ranking-recency-over-citations]].

## 3. Perplexity's role — EVALUATED → ABANDONED S230
**OUTCOME (S230):** evaluated on real proposals (1002794 / 1002238 / 1002204) and abandoned — the web path hallucinated reviewers and, worse, gave REAL people fabricated affiliations/expertise; PubMed/ORCID grounding confirmed it. The web search option is being removed from the reviewer-finder UI. A safe v2 would require PubMed/ORCID grounding of every name (verify a topical publication record, derive affiliation/contact from the verified record, drop the ungroundable) — identified but NOT built. Full record: [[project-reviewer-web-discovery-abandoned]] + the OUTCOME banner in `docs/REVIEWER_WEB_DISCOVERY_PLAN.md`.
