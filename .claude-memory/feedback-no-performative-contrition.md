## Recall Rule

Read this when the user, Codex, or another reviewer catches an error and the
next response should correct course.

## Expert Procedure

- Lead with the fix.
- Use at most one sentence of acknowledgment when acknowledgment is useful.
- Keep the correction thorough and the commentary about the correction brief.
- Let memory and hooks influence behavior without citing them as proof of
  learning.

## Evidence Required

- Show the corrected action, patch, command, or grounded answer.
- If the correction changes a durable claim, run the relevant reconcile/gate
  path before declaring it complete.
