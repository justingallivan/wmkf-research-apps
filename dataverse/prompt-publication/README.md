# PR553 Dataverse SDK milestone

This now includes compiled **publication lifecycle, SDK persistence and
authorization/write-guard evaluators**, not a registered publication plug-in.
`IPublicationRules` has only a test stub: the complete production format,
budget and live catalog/removal port is still required. No IPlugin/Custom API, target login, schema
installer, role grant or live rehearsal runner is included. The existing Admin
and budget writers are not switched. Connor remains the operation maintainer.

Transport targets .NET Framework 4.8 for the eventual plug-in and net8.0 for local
macOS checks of the same source. Dependencies are pinned in NuGet lockfiles and
restore uses only the explicit public NuGet feed. No project/provider API key is
used. Build outputs stay ignored; signing/plug-in packaging is still pending. The
net48 library depends on Newtonsoft.Json: use the supported dependent-assembly
plug-in package model, not a lone DLL upload. No such package is built here.

```
PR553_DOTNET=/absolute/path/to/dotnet PR553_NUGET_CACHE=/private/tmp/pr553-nuget bash scripts/check-prompt-publication-sdk.sh
```

The SDK 8.0.427 toolchain was installed in `/private/tmp/pr553-dotnet`, leaving the
machine PATH/global installation unchanged. The runner stores CLI state/caches
in temporary directories, builds net48 and net8, runs the offline net8 harness,
and checks the source-hashed rehearsal packet. A package restore may access the
public NuGet feed, but no tenant or provider. Offline cached `--no-restore` builds
are also possible. Restore in the Codex sandbox initially failed to reach NuGet;
the host restore succeeded with the same isolated paths and public-only config.

- `TransactionSdk`: server-owned context/organization/effective-actor binding,
  transaction rechecks, exact original weak ETag to SDK RowVersion, conditional
  updates, create-only writes, explicit projections and ordered complete paging.
  Faults propagate with no batch, retry, unconditional-update or SYSTEM fallback.
  Paging completes the visible query only: approved organization-wide Read must
  be proved before its result can attest complete publication history.
- `PromptRows`: existing table inventory with no status/current filter; explicit
  promotion stamps plus draft-baseline clear; previous row only loses current.
- `PromptSchemaPreflight`: read-only organization and published metadata report
  for basic lifecycle and proposed additive columns. It neither provisions nor
  attests all schema/roles/keys. Expected organization is server-owned; the future
  caller must independently bind the approved sandbox endpoint and organization.
- `CanonicalJson`: strict bounded JSON and exact tagged preimages/hashes for the
  two existing v1 hash domains. No definition/request/receipt/role validation.
  Fingerprint and JS-oracle wire goldens run on net8; actual net48 runtime and the full
  format/template/model/budget validator suite remain rehearsal gates.

`rehearsal/packet.json` is generated by
`node scripts/build-prompt-publication-rehearsal.cjs`; `--check` detects drift.
It pins source/lock/golden/policy hashes and 21 cases, with null live bindings and
both authority booleans false. There is no execute mode. A separately reviewed
release manifest must establish actual sandbox org/API/table/role/index bindings,
completed .NET validators and guarded transaction behavior before rehearsal.
See the SDK milestone record and the Pre-Site transition runbook under docs/plans.


## Composition and Framework rehearsal gates

`PublicationSdkStore` supplies the complete lifecycle/catalog inventory and
Executor definition/baseline DTO using real SDK operations and exact ETags.
`PromptRows.ReadInventory` remains a narrow transport helper, not that DTO.
Owner-selected native head columns/prompt lookup and the receipt JSON payload
require schema, Active keys
and metadata proof before use. Approved identity/privilege/API-extension bindings
remain server-owned and unprovisioned. Organization-wide Read is checked using
team-aware effective privilege depth, but actual tenant access/intersection and
parent/permit propagation must still be rehearsed. See
`docs/plans/SHARED_PROMPT_PUBLISHER_MILESTONE_2026-10-30.md` for the lifecycle,
authorization, temporary raw-write restrictions and missing production rules.
No IPlugin entry or deployable solution is supplied.
The build emits `Checks/bin/Release/net48/Checks.exe` for the actual Windows
Framework runtime. Run it with the absolute shared fingerprint fixture path;
it also reads adjacent `sdk-numbers-v1.json`. That numeric fixture includes
17-significant-digit mantissas, half-even rounding boundaries, subnormal/normal
limits and underflow. It currently passes on net8 only. A Framework mismatch
blocks release and requires a correctly rounded parser; do not waive it because
the simpler original fingerprints pass. Full format parity remains separate.
